# AI Agent Manager v0.3.0

## Highlights

- Real-time agent response streaming, including Codex App Server text deltas.
- Markdown and code block rendering while responses arrive.
- Improved desktop session UI and agent activity presentation.
- Provider rate-limit diagnostics, safe continuation handling and usage reporting.
- CLI latency benchmarks and regression test coverage.
- Desktop packaging workflows for Windows and Linux.

## Validation and limitations

- Codex live streaming was visually confirmed by the user.
- Cross-platform installer smoke tests, macOS signing/notarization, and full end-to-end provider recovery are not yet verified.
- Release binaries must not be described as validated until build and installation checks pass.
