# v1.1.0 — Project AI Architect

## Added
- Offline, bounded source inventory and generated project instructions, reviewer subagent and workflow skill.
- Unified CLI and interactive terminal/Textual diff preview and explicit approval.
- SHA-256 manifest for safe generated-file refresh.
- Adoption of unchanged files produced by the earlier standalone generator.
- Regression tests for initial generation, refresh, user-edit conflicts, symlink safety and stale previews.

## Compatibility and limitations
- Python 3.10+; no new mandatory runtime dependencies.
- Existing AGENTS.md and CLAUDE.md remain untouched.
- User-edited generated files are marked as conflicts and preserved.
- Smart Router discovers generated project context; native Claude/Codex instruction loading remains provider-specific.
- Analysis is static and heuristic, not full AI semantic architecture reasoning.
- Authenticated end-to-end tests against actual Claude/Codex CLIs are not part of CI.

Release only after all Python CI jobs pass. Tag should point to the merged main commit.
